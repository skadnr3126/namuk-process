# 구현 후 리뷰 명세

메인이 구현 결과를 받은 뒤 사전 변경 검토자·구현자와 별도인 리뷰 전용 서브에이전트에 전달한다. 작은 변경은 짧게 작성한다. 메인은 `code-review/SKILL.md`의 실제 원본 경로와 상대 참조 기준 폴더를 명시해 읽도록 한다. 설계 판단 기준은 통합 코드베이스 설계를 참조하고 명세에 복사하지 않는다.

```text
목적과 승인된 범위
- 작업 목적, 승인된 변경 시나리오와 승인 근거, 완료 기준
- 허용한 계약 변경, 보존할 계약·데이터, 제외 범위

검토 대상과 근거
- 저장소와 작업 트리, 기준 ref 또는 확인 가능한 변경 전 상태
- 실제 변경 파일·범위, 미추적 신규 파일, 구분해야 할 기존 사용자 변경
- 영향받는 호출자와 관련 검증 경로
- 구현자가 반환한 검증 결과·실행 조건·실패·미확인
- 리뷰 대상의 쓰기 중지 시점과 이후 변경 여부

권한과 반환
- 읽기 전용으로 실제 diff·신규 파일·호출부를 읽고 메인에만 반환
- 수정·커밋·푸시·사용자 승인·완료 판단·재위임 금지
- 검토한 버전·범위와 조사 한계
- 발견사항별 심각성, 발동 조건, 근거 위치, 기대와 실제 동작, 확인 방법
- 재검토라면 이전 지적의 해결·미해결·미확인, 최종 변경과 관련 영향
- 필요한 추가 검증과 사용자 결정, 실행하지 못한 이유
```

기준 버전이나 미추적 파일을 포함한 실제 범위를 확인하지 못하면 검토 한계로 반환한다. 별도 상태 기록 파일이나 해시 등록 절차를 요구하지 않는다. 메인은 반환 결과를 완료 근거와 대조하고 채택하지 않은 의견에도 근거를 남긴다. 리뷰 이후 대상이 달라지면 달라진 변경과 영향을 같은 리뷰자에게 다시 전달한다.
