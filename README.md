# namuk-process

사용자의 요청을 이해하고, 실제 맥락과 원하는 결과에 맞는지 점검해 더 나은 요청을 돕는 플러그인입니다. 상황에 필요한 검증만 선택합니다.

- [요청의 명확성](skills/verify-request-clarity/SKILL.md): 다음 행동을 정할 최소 정보가 있는지 확인합니다.
- [맥락과의 적합성](skills/verify-request-context/SKILL.md): 요청을 코드·환경·설계와 대조합니다.
- [문제와 수단의 일치](skills/verify-request-alignment/SKILL.md): 요청한 작업이 원하는 결과에 도움이 되는지 점검합니다.
