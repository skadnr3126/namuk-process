# 남욱 프로세스

사용자의 의도를 검증 가능한 요청으로 정리하고, 같은 설계 기준으로 구현한 뒤 결과를 완료 기준과 대조하는 플러그인입니다.

[개발 작업 흐름](skills/development-workflow/SKILL.md)은 다음 네 단계를 연결합니다.

1. 의도를 이해하고, 원하는 결과와 완료 기준을 정리합니다.
2. 요청의 불확실한 부분에 필요한 검증을 선택합니다.
3. [코드베이스 설계](skills/codebase-design/SKILL.md)를 참고해 설계하고, 구현할 때도 그 설계 기준을 따릅니다.
4. 실제 결과를 처음의 완료 기준과 대조합니다.

이미 확보한 맥락은 재사용하고, 작은 수정은 짧게 진행합니다. 요청 검증은 필요한 것만 선택합니다.

- [요청의 명확성](skills/verify-request-clarity/SKILL.md): 다음 행동을 정할 최소 정보가 있는지 확인합니다.
- [맥락과의 적합성](skills/verify-request-context/SKILL.md): 요청을 코드·환경·설계와 대조합니다.
- [문제와 수단의 일치](skills/verify-request-alignment/SKILL.md): 요청한 작업이 원하는 결과에 도움이 되는지 점검합니다.
